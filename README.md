# 🚀 Meme Trader - Paper Trading Engine

High-performance paper trading engine für Krypto-Tokens mit AI-Filter und Advanced Risk Management.

## Features

✅ Paper Trading Simulation  
✅ AI Token Validation  
✅ Advanced Risk Management (SL, TP1, TP2, Trailing Stop)  
✅ Real-time Monitoring  
✅ Discord Notifications  
✅ Atomic Database Operations  
✅ Price Caching & Fallback  
✅ Emergency Shutdown  

## Quick Start

```bash
pip install -r requirements.txt
python backend/main.py
```

## Setup

1. Clone the repo
2. Create `.env` file
3. Run `pip install -r requirements.txt`
4. Start with `python backend/main.py`
